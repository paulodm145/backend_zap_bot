# Diagnóstico inicial obrigatório

Antes da primeira implementação neste repositório:

1. leia integralmente `docs/PRD.md` e `docs/ARQUITETURA-BACKEND.md`;
2. inspecione código, dependências, configurações e testes existentes;
3. apresente separadamente:
   - implementado e alinhado;
   - implementado com divergência específica;
   - ainda pendente;
4. não altere código durante essa análise;
5. aguarde a priorização do usuário.

Se uma tarefa posterior tocar uma divergência diagnosticada, avise o usuário
antes de implementar e não resolva a divergência por conta própria.
